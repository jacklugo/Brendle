# Brendle ✈️

Three daily aviation games from "Brendan Air". Everyone gets the same puzzles each day, then shares an emoji scoreboard.

- **Brendan's Layover** (airports): guess the mystery airport in 6; each miss shows distance and direction.
- **Where's Brendan?** (geography): tap five cities on a world map; lowest total miles off wins.
- **Brendan's Hangar** (planes): guess the aircraft in 6 from maker, engines, body, seats, range and first flight.

Plain static site (HTML/CSS/JS modules), no build step. Deploy as-is on Vercel.

Data: airports from [OurAirports](https://ourairports.com/data/) (public domain); map from [Natural Earth](https://www.naturalearthdata.com/) (public domain); aircraft figures are typical approximate values.
